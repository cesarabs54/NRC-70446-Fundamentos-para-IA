¿El dataset está limpio?

Antes de sacar conclusiones hay que verificar tres cosas: valores nulos, registros duplicados y valores atípicos. En este dataset el resultado es "limpio", pero el diagnóstico se hace siempre — no porque se espere encontrar problemas, sino porque no puedes saberlo sin comprobarlo con isnull(), duplicated() y una regla de atípicos como el rango intercuartílico (IQR).

Valores atípicos — regla del rango intercuartílico (IQR)

Un valor se considera atípico si cae fuera de [Q1 − k·IQR, Q3 + k·IQR], con IQR = Q3 − Q1. El valor habitual de k es 1.5; muévelo para ver cómo cambia el diagnóstico.

Código equivalente en Python

Aprenderás: que "atípico" depende de una regla y un umbral que tú eliges, no es un hecho absoluto — por eso se reporta junto con el criterio usado.

El código equivalente en pandas

df.isnull().sum()          # nulos por columna
df.duplicated().sum()      # filas duplicadas

q1 = df["math score"].quantile(0.25)
q3 = df["math score"].quantile(0.75)
iqr = q3 - q1
lo, hi = q1 - 1.5 * iqr, q3 + 1.5 * iqr
atipicos = df[(df["math score"] < lo) | (df["math score"] > hi)]
