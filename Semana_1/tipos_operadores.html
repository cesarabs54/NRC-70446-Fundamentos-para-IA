Adivina el tipo

Para cada variable del registro de un experimento, elige el tipo de dato correcto — igual que type() en el Ejercicio 2.

Dato clave: None es el valor propio de Python para "ausencia de valor" — distinto de 0, "" o False. Si alguien usa "N/A" en su lugar, deja de ser un tipo especial y rompe comparaciones como if observaciones is None.
