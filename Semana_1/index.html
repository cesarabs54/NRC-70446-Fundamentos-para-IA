Fundamentos para IA · Semana 1

Introducción a Python para inteligencia artificial

Cuatro recursos cortos e interactivos para practicar la sintaxis básica de Python en torno al mismo hilo conductor de los ejercicios de clase de la semana: construir, en Python puro, las piezas de un pequeño sistema para registrar experimentos de entrenamiento de modelos de Machine Learning. Ejecuta el REPL paso a paso, arma listas y diccionarios, recorre bucles y prueba el manejo de errores — cada módulo se puede explorar de forma independiente.

Módulo 1 · Fundamentos

El intérprete, tipos y operadores

Ejecuta el REPL línea por línea, adivina el tipo de cada variable de un experimento y compara dos modelos moviendo sliders de accuracy.

Aprenderás: cómo Python evalúa expresiones y por qué cada tipo de dato importa.

 Módulo 2 · Colecciones

Listas, tuplas, conjuntos y diccionarios

Agrega y ordena una lista de accuracy, intenta "editar" una tupla inmutable, elimina duplicados con un set y arma un diccionario de experimento.

Aprenderás: cuándo usar cada estructura según si necesitas orden, unicidad o inmutabilidad.

 Módulo 3 · Control de flujo

Condicionales, bucles y funciones

Clasifica un experimento con un gauge en vivo, prueba un match/case de optimizadores y recorre un bucle paso a paso hasta encontrar el mejor modelo.

Aprenderás: cómo un if decide, cómo un bucle acumula estado y por qué encapsular en funciones ayuda a reutilizar lógica.

 Módulo 4 · Robustez

Errores, archivos y módulos

Prueba el validador try/except con datos válidos e inválidos, sigue el flujo de escritura/lectura de un archivo y observa cómo colaboran dos módulos con import.

Aprenderás: a anticipar errores comunes de datos y a organizar el código en más de un archivo.
Sugerencia de recorrido: los módulos siguen el orden de los ejercicios de clase — primero el intérprete y los tipos básicos, luego las colecciones de datos, después el control de flujo y las funciones y, al final, el manejo de errores, archivos y módulos. Pero cada uno funciona solo, así que puedes explorarlos en cualquier orden.
Recurso complementario al material de la Semana 1 (versión profesor), no lo reemplaza. Basado en el hilo conductor de registrar experimentos de entrenamiento de modelos de Machine Learning en Python puro.
