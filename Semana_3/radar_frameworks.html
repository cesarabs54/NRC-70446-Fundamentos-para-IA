Radar de criterios: ¿qué framework conviene?

Los 6 criterios técnicos de la pregunta orientadora del foro —preprocesamiento, GPU/rendimiento, facilidad de entrenamiento, interpretabilidad, comunidad/documentación e integración para despliegue— puntuados de 1 a 5 para cada framework. Elige un escenario para ver cuál se ajusta mejor.

Comparación por escenario

Scikit-learn TensorFlow/Keras PyTorch

Scikit-learn ✓ mejor ajuste

from sklearn.linear_model import LinearRegression

modelo = LinearRegression()
modelo.fit(X, y)
modelo.predict(X_nuevo)

TensorFlow/Keras ✓ mejor ajuste

modelo = tf.keras.Sequential([
    tf.keras.layers.Dense(1)
])
modelo.compile(optimizer="sgd", loss="mse")
modelo.fit(X, y, epochs=50)

PyTorch ✓ mejor ajuste

modelo = nn.Linear(1, 1)
opt = torch.optim.SGD(modelo.parameters(), lr=0.01)

for _ in range(50):
    opt.zero_grad()
    perdida = nn.MSELoss()(modelo(X), y)
    perdida.backward()
    opt.step()
