Los paneles de arriba omiten imports e impresiones para poder comparar líneas de forma justa. Aquí tienes cada versión completa y lista para copiar en tu notebook:

Código equivalente — Scikit-learn

from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

X = [[1], [2], [3], [4]]
y = [2, 4, 6, 8]

modelo = LinearRegression()
modelo.fit(X, y)
modelo.predict([[5]])
mean_squared_error(y, modelo.predict(X))

Código equivalente — TensorFlow/Keras

import tensorflow as tf

X = [[1], [2], [3], [4]]
y = [2, 4, 6, 8]

modelo = tf.keras.Sequential([
    tf.keras.layers.Input(shape=(1,)),
    tf.keras.layers.Dense(1)
])
modelo.compile(optimizer="sgd", loss="mse")
modelo.fit(X, y, epochs=200)

Código equivalente — PyTorch

import torch
from torch import nn

X = torch.tensor([[1.], [2.], [3.], [4.]])
y = torch.tensor([[2.], [4.], [6.], [8.]])

modelo = nn.Linear(1, 1)
opt = torch.optim.SGD(modelo.parameters(), lr=0.01)
perdida = nn.MSELoss()

for _ in range(200):
    opt.zero_grad()
    error = perdida(modelo(X), y)
    error.backward()
    opt.step()

modelo(torch.tensor([[5.0]]))
