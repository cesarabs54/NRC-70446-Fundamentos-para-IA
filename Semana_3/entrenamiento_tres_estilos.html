PyTorch — bucle manual, paso a paso
modelo = nn.Linear(1, 1)
opt = torch.optim.SGD(modelo.parameters(), lr=0.01)
perdida = nn.MSELoss()

for _ in range(200):
    opt.zero_grad()
    error = perdida(modelo(X), y)
    error.backward()
    opt.step()

Pregunta de reflexión (taller, Parte 3): en Keras todo el entrenamiento ocurre dentro de una sola línea (model.fit(...)); en PyTorch tuviste que escribir cada paso (zero_grad, backward, step). ¿Qué ventaja y qué desventaja le ves a esta diferencia? Nota cómo scikit-learn ni siquiera necesita épocas: para una regresión lineal simple, existe una solución matemática exacta.
